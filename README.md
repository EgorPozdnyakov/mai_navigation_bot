# Карта столовых МАИ (Telegram Mini App)

Студенческий проект по дисциплине «Обучение служением». Интерактивная карта столовых основной
территории МАИ (метро «Сокол»). Нажимаешь на метку — снизу выезжает карточка: открыта ли столовая
сейчас, где находится, часы работы, средний чек, оплата, доступность и кнопка «Меню».

> Это неофициальный студенческий проект, а не сервис МАИ.

Сайт: https://egorpozdnyakov.github.io/mai_navigation_bot/ · Бот: [@StolovayaMAI_bot](https://t.me/StolovayaMAI_bot)

Что умеет:

- карта кампуса с 10 столовыми, приближение пальцами;
- «Открыто сейчас» по московскому времени;
- фильтры «Открыто сейчас» и «♿ Для маломобильных»;
- список столовых с поиском по названию;
- фото столовой и фото меню;
- ссылки и QR-коды на конкретную столовую;
- светлая и тёмная тема (в Telegram — цвета темы Telegram).

---

## 1. Как устроено

Ни сервера, ни базы данных, ни подгружаемых таблиц нет — это статический сайт на GitHub Pages.
Все данные о столовых лежат прямо в коде, в файле **`js/places.js`**.

- **Карта — это картинка** `media/map.jpg`. Библиотека [Leaflet](https://leafletjs.com) в режиме
  `L.CRS.Simple` позволяет двигать и приближать её как обычную карту.
- **Метки** ставятся по `x`, `y` — пикселям картинки от левого верхнего угла.

```
├── index.html       — разметка и тексты интерфейса
├── css/style.css    — внешний вид, светлая и тёмная тема
├── js/
│   ├── places.js    — ДАННЫЕ: все столовые
│   ├── hours.js     — «открыто сейчас»
│   ├── map.js       — карта и метки
│   └── app.js       — всё остальное: фильтры, список, карточка, меню, Telegram
├── media/           — map.jpg (карта) и photos/ (фото столовых и меню)
├── vendor/leaflet/  — Leaflet 1.9.4 (лежит в проекте, CDN бывают недоступны)
├── bot/             — Telegram-бот на aiogram (кнопка «Открыть карту»)
└── tests/           — проверки (node --test или tests/tests.html)
```

## 2. Как поменять данные

Откройте `js/places.js` (на GitHub — значок ✏️ «Edit»). Одна столовая выглядит так:

```js
{
  id: 1, name: 'Столовая у КПП №5', where: 'Корпус 7, 3 этаж',
  open: '9:00', close: '17:00', price: 400, payment: 'наличные и карта', accessible: false,
  x: 395, y: 69, photos: [], menu: [],
},
```

| Поле | Что писать |
|---|---|
| `id` | номер на метке и в ссылке `?place=N`, не должен повторяться |
| `name`, `where` | название и где находится — текст в кавычках |
| `open`, `close` | часы работы в будни, `'9:00'` и `'17:00'`. В субботу и воскресенье закрыто |
| `price` | средний чек в рублях, просто число |
| `payment` | оплата, текстом |
| `accessible` | `true` — можно попасть без ступенек, `false` — нельзя |
| `x`, `y` | где метка на картинке карты. Откройте сайт с `?debug=1` и нажмите на карту — увидите числа |
| `photos` | фото столовой: `['1-1.jpg', '1-2.jpg']`, первое — главное |
| `menu` | фото меню: `['1-menu.jpg']`. Пусто — на кнопке «Меню» будет «пока не добавили» |

Текст пишется в одинарных кавычках, после каждого поля — запятая. Если ошиблись, проверки
(раздел 3) подскажут, в какой столовой ошибка.

### Фото

1. Положите файлы в `media/photos/` (на GitHub: папка `media/photos` → **Add file → Upload files**).
   Имена латиницей без пробелов, удобно по номеру столовой: `1-1.jpg`, `1-menu.jpg`.
   Желательно сжать до ~1200 px по ширине и 300 КБ ([squoosh.app](https://squoosh.app)).
2. Впишите имена в `photos` или `menu` нужной столовой в `js/places.js`.

Если файла нет или имя с ошибкой, фото просто не покажется.

## 3. Запуск на своём компьютере

Нужен Python 3. В папке проекта:

```bash
python -m http.server
```

и откройте **http://localhost:8000** (на Windows, если `python` не находится, — `py -m http.server`).
Просто открыть `index.html` двойным кликом нельзя: браузер не даст загрузить модули.

| Адрес | Что делает |
|---|---|
| http://localhost:8000/?place=3 | сразу открыть столовую № 3 |
| http://localhost:8000/?debug=1 | режим разметки: нажмите на карту — увидите `x` и `y` |
| http://localhost:8000/tests/tests.html | проверки в браузере |

**Проверки** — часы работы, «открыто сейчас» и правильность данных в `js/places.js`:
`node --test` (Node.js 20+) или страница `tests/tests.html`. На GitHub они запускаются сами
при каждом push.

## 4. Публикация и Telegram

**Сайт** публикуется через GitHub Pages из ветки `claude/adoring-feynman-fz08ls`
(Settings → Pages). После каждого push сайт обновляется сам за 1–2 минуты.

**Бот** — папка `bot/`, простой бот на [aiogram 3](https://docs.aiogram.dev): на `/start` присылает
кнопку «Открыть карту» и ставит кнопку «Карта» рядом с полем ввода.

```bash
pip install -r bot/requirements.txt
BOT_TOKEN=123:abc python bot/bot.py
```

На Windows: `set BOT_TOKEN=123:abc`, затем `python bot/bot.py`. Бот отвечает, только пока запущен,
поэтому для постоянной работы его нужно запустить на сервере. **Токен не храните в коде и не
отправляйте в git.**

**Ссылки и QR-коды на столовую:**

- `https://t.me/StolovayaMAI_bot?start=place_3` — бот пришлёт кнопку, которая откроет столовую № 3;
- `https://egorpozdnyakov.github.io/mai_navigation_bot/?place=3` — то же в обычном браузере.

Приложение не собирает и никуда не отправляет данные пользователей.

## 5. Если что-то не работает

| Что видно | Что проверить |
|---|---|
| Белый экран | Откройте консоль (`F12` → Console). Скорее всего, ошибка в `js/places.js`: пропущена запятая или кавычка |
| «Не удалось загрузить карту кампуса» | Есть ли файл `media/map.jpg`? |
| Метка не на месте | Проверьте `x` и `y` через `?debug=1` |
| Бот молчит | Бот не запущен — см. раздел 4 |
| В Telegram старая версия | Подождите пару минут, закройте карту полностью и откройте снова |
