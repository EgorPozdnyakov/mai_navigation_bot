# Карта столовых и коворкингов МАИ (Telegram Mini App)

Студенческий проект по дисциплине «Обучение служением». Интерактивная карта основной
территории МАИ (метро «Сокол»): столовые, буфеты, кафе и коворкинги. Нажимаешь на метку —
снизу выезжает карточка: открыто ли сейчас, где находится, часы работы, цены, доступность,
кнопки «Меню» и «Маршрут».

> Это неофициальный студенческий проект, а не сервис МАИ.

Приложение работает и внутри Telegram (Mini App), и в обычном браузере.

---

## 1. Как это устроено

```
картинка карты (media/map.jpg)  +  метки (data/objects.csv)  +  меню (data/menu.csv)
```

- **Карта — это картинка**, а не Яндекс/Google-карта. Библиотека [Leaflet](https://leafletjs.com)
  в режиме `L.CRS.Simple` позволяет двигать и приближать картинку пальцем, как обычную карту.
- **Метки** ставятся по координатам `map_x`, `map_y` — это пиксели картинки, считая от её
  левого верхнего угла.
- **Данные** лежат в CSV-таблицах. Их разбирает библиотека [Papa Parse](https://www.papaparse.com).
- Ни сервера, ни базы данных нет: это статический сайт, его можно разместить на GitHub Pages.

Библиотеки лежат в папке `vendor/` (не подключаются с CDN — CDN бывают недоступны):

| Библиотека | Версия | Файлы |
|---|---|---|
| Leaflet | **1.9.4** | `vendor/leaflet/leaflet.js`, `leaflet.css`, `images/` |
| Papa Parse | **5.7.0** | `vendor/papaparse/papaparse.min.js` |

Telegram Web App SDK подключается официальным скриптом `https://telegram.org/js/telegram-web-app.js`.

## 2. Как запустить на своём компьютере

Нужен Python 3 (он есть почти везде; на Windows ставится с python.org).

1. Откройте терминал в папке проекта (там, где лежит `index.html`).
2. Запустите простой веб-сервер:

   ```bash
   python -m http.server
   ```

   На Windows, если `python` не находится, попробуйте `py -m http.server`.
3. Откройте в браузере **http://localhost:8000**
4. Остановить сервер — `Ctrl+C` в терминале.

**Почему нельзя просто открыть `index.html` двойным кликом?** Тогда адрес начинается
с `file://`, и браузер из соображений безопасности запрещает странице загружать модули
JavaScript (`import`) и файлы данных (CSV). Приложение не запустится — на экране будет
подсказка запустить сервер. Через `http://localhost` всё работает так же, как на настоящем сайте.

Полезные адреса при запуске на компьютере:

| Адрес | Что делает |
|---|---|
| http://localhost:8000 | приложение |
| http://localhost:8000/?place=3 | сразу открыть карточку места № 3 |
| http://localhost:8000/?debug=1 | режим разметки (координаты по нажатию) |
| http://localhost:8000/tests/tests.html | проверки в браузере |

Чтобы посмотреть, как приложение выглядит на телефоне, в Chrome нажмите `F12` →
значок телефона (Device Toolbar) → выберите ширину 375 px.

### Тесты

Чистые функции (разбор часов, «открыто сейчас», проверка строк CSV, ссылки `place_N`)
проверяются автоматически. Интернет не нужен.

- Если установлен **Node.js** (версия 20 или новее): в папке проекта выполните

  ```bash
  node --test
  ```

  В конце должно быть `# fail 0`.
- Если Node.js нет — запустите сервер (см. выше) и откройте
  http://localhost:8000/tests/tests.html. Должно быть «Все проверки прошли».

Проверки лежат в `tests/hours.cases.js` и `tests/data.cases.js` — их запускают оба способа.

## 3. Картинка карты

Сейчас в `media/map.jpg` лежит схема кампуса с сайта **mai-sten.online** (800×700 px).
**Перед публикацией спросите у автора схемы разрешение** на её использование. Подпись
«Карта: mai-sten.online» стоит в правом нижнем углу карты и в окне «О проекте»; поменять её
можно в `js/texts.js` (`map.credit` и `about.paragraphs`).

### Какая картинка нужна

- Формат **JPEG** (`.jpg`), имя файла — `map.jpg`.
- Длинная сторона — **3000–4000 px**, не больше 4096 px (иначе на старых телефонах может
  не загрузиться).
- Вес — **до 2–3 МБ** (по мобильному интернету большая картинка грузится долго).
- Текущая картинка 800×700 подходит только для демонстрации: при приближении она мыльная.
  На картинке указано, что на mai-sten.online/plan есть «полная версия» — найдите её,
  **прежде чем расставлять метки**.

Размеры картинки приложение узнаёт само при загрузке, в коде их менять не нужно.

### Как сжать картинку

- В браузере: сайт [squoosh.app](https://squoosh.app) → перетащите картинку →
  в настройках включите Resize и задайте длинную сторону 4000 px → формат «MozJPEG»,
  качество 75–80 → скачайте результат.
- В GIMP или Paint.NET: «Изображение → Размер изображения» (длинная сторона 4000 px),
  затем «Экспортировать как JPEG», качество 80.
- Если установлен ImageMagick:

  ```bash
  magick map_big.png -resize "4000x4000>" -quality 80 media/map.jpg
  ```

### ⚠️ Если поменять картинку на другую по размеру

Координаты `map_x`, `map_y` — это пиксели **конкретной** картинки. Если положить ту же карту,
но другого размера (например, 4000 px в ширину вместо 800), все метки съедут. Их нужно
пересчитать:

```
новый map_x = старый map_x × (новая ширина / старая ширина)
новый map_y = старый map_y × (новая высота / старая высота)
```

Пример: картинка была 800 px, стала 4000 px → умножить все `map_x` и `map_y` на 5.
В Google Таблицах это формула вида `=ROUND(Q2*4000/800)` в соседней колонке.
Если карта другая (не просто увеличенная), метки придётся расставить заново (см. раздел 4).

## 4. Как добавить место

1. **Добавьте строку** в `data/objects.csv` (или в общую таблицу — см. раздел 7).
2. **Найдите координаты на карте.** Откройте приложение с `?debug=1`
   (например, http://localhost:8000/?debug=1). Нажмите на карте туда, где должна стоять метка:
   появятся `map_x` и `map_y` и кнопка «Скопировать». Скопированные числа при вставке в
   Google Таблицу или Excel сами разложатся в две соседние ячейки (`map_x`, `map_y`).
   В этом режиме рядом с метками видны их id и координаты — удобно проверять.
3. **Найдите координаты входа** (`lat`, `lon`) для кнопки «Маршрут»: в Яндекс Картах нажмите
   на вход в корпус — внизу появятся координаты вида `55.811070, 37.500900`.
   Первое число — `lat`, второе — `lon`.
4. **Добавьте фото** (по желанию) в `media/photos/` и впишите имена файлов в колонку `photos`.
5. Сохраните, обновите страницу (`Ctrl+F5`) и проверьте карточку. Откройте консоль браузера
   (`F12` → Console): если в строке что-то не так, там будет предупреждение с id места
   и названием поля.

### Колонки `objects.csv`

Названия колонок — латиницей, как в первой строке файла. Кодировка UTF-8.

| Колонка | Что писать | Пример |
|---|---|---|
| `id` | уникальный номер, только цифры, больше 0. Он же номер на метке и в ссылке `place_N` | `3` |
| `type` | `столовая` / `буфет` / `кафе` / `автоматы` / `коворкинг` | `кафе` |
| `name` | название | `Кафе в 24 корпусе` |
| `building` | корпус | `24` |
| `floor` | этаж | `1` |
| `how_to_find` | как найти, коротко | `Вход со двора` |
| `hours_weekdays` | часы в будни: `ЧЧ:ММ-ЧЧ:ММ` или `закрыто` | `08:30-17:00` |
| `hours_saturday` | часы в субботу: так же | `закрыто` |
| `break` | перерыв (действует во все рабочие дни) или пусто | `13:00-13:30` |
| `payment` | оплата, свободным текстом | `карта, наличные` |
| `lunch_price` | примерная цена обеда, **только цифры** | `350` |
| `vegetarian` | есть ли вегетарианское: `да` / `нет` | `да` |
| `accessible` | доступно для маломобильных: `да` / `частично` / `нет` | `частично` |
| `accessibility_note` | пояснение к доступности | `Лифта нет` |
| `lat`, `lon` | координаты входа (точка или запятая) | `55.81107`, `37.50090` |
| `map_x`, `map_y` | положение метки на картинке, пиксели (см. `?debug=1`) | `391`, `313` |
| `seats` | число мест (для коворкингов), только цифры | `30` |
| `sockets` | розетки: `много` / `мало` / `нет` | `много` |
| `wifi` | `да` / `нет` | `да` |
| `noise` | `тихо` / `шумно` | `тихо` |
| `photos` | имена файлов из `media/photos/` через запятую | `kafe-1.jpg,kafe-2.jpg` |
| `visible` | `нет` — не показывать место (например, на ремонте). Пусто или `да` — показывать | `да` |
| `updated` | когда проверяли данные: `ДД.ММ.ГГГГ` | `03.11.2026` |

Правила:

- **Воскресенье** всегда считается выходным (отдельной колонки нет).
- Работа «через полночь» (например, `20:00-02:00`) не поддерживается.
- Время «открыто сейчас» считается **по Москве**, даже если на телефоне другой часовой пояс.
- Пустая ячейка — поле в карточке не показывается. Ячейка с ошибкой (например, `с 8 до 5`
  в часах или `300 руб.` в цене) показывается как «нет данных», а в консоли появляется
  предупреждение.
- Строка с неправильным `id` пропускается целиком. Место без `map_x`/`map_y` не ставится
  на карту, но остаётся в списке.
- Если в ячейке есть запятая (например, в `photos` или `payment`), ячейку нужно взять
  в двойные кавычки: `"карта, наличные"`. Excel и Google Таблицы делают это сами при
  сохранении в CSV.
- Excel с русскими настройками сохраняет CSV через точку с запятой — это тоже работает.
  Сохраняйте как **«CSV UTF-8»**, иначе русские буквы превратятся в «кракозябры».

### Колонки `menu.csv`

| Колонка | Что писать | Пример |
|---|---|---|
| `object_id` | `id` места из `objects.csv` | `1` |
| `category` | `первое` / `второе` / `гарнир` / `салат` / `выпечка` / `напитки` / `комплекс` | `первое` |
| `dish` | название блюда | `Борщ со сметаной` |
| `price` | цена, только цифры | `120` |
| `vegetarian` | `да` / `нет` | `нет` |
| `updated` | `ДД.ММ.ГГГГ` | `01.11.2026` |

Блюдо с неизвестной категорией попадает в раздел «Другое». Кнопка «Меню» есть у всех мест
питания; если блюд нет, на экране меню будет «Меню этого места пока не добавили».

### Фото

- Имена файлов — **латиницей, без пробелов**: `stolovaya-guk-1.jpg`.
- Формат JPEG (или PNG/WebP), ширина около 1200 px, вес до 300 КБ (сжать — squoosh.app).
- Фото загружаются, только когда до них долистали (`loading="lazy"`).
- Если файла нет — фото просто не показывается, в консоли будет предупреждение.

### Демо-данные

Сейчас в таблицах **демонстрационные** места («Демо-столовая 1» и т. п.). Специально:

- у «Демо-буфета 1» (id 2) часы записаны с ошибкой («с 8 до 5») — в консоли будет
  предупреждение, в карточке «нет данных»;
- «Демо-коворкинг 2» (id 5) скрыт (`visible = нет`).

Координаты демо-меток поставлены **примерно**, по значкам общепита на схеме, а `lat`/`lon` —
примерные координаты кампуса. Перед запуском замените демо-строки настоящими данными.

## 5. Публикация на GitHub Pages

1. Загрузите проект в репозиторий на GitHub (файл `index.html` должен лежать в корне
   репозитория или в папке `docs/`).
2. На странице репозитория: **Settings → Pages**.
3. В «Build and deployment» → Source выберите **Deploy from a branch**.
4. Branch: `main` (или ваша ветка), папка `/ (root)` (или `/docs`) → **Save**.
5. Через 1–2 минуты сайт появится по адресу `https://<ваш-логин>.github.io/<имя-репозитория>/`
   (для этого репозитория — https://egorpozdnyakov.github.io/mai_navigation_bot/).
   Ссылка будет вверху страницы Settings → Pages.
6. После каждого `git push` сайт обновляется сам (обычно за 1–2 минуты).

Файл `.nojekyll` уже лежит в корне: он говорит GitHub Pages не обрабатывать файлы,
а отдавать как есть. Все пути в проекте относительные, поэтому сайт работает и в подпапке.

## 6. Подключение к Telegram-боту

Mini App открывается по HTTPS-ссылке на сайт (GitHub Pages даёт HTTPS).
Ниже `https://<сайт>/` — адрес из раздела 5.

### Кнопка меню бота (слева от поля ввода)

В [@BotFather](https://t.me/BotFather): `/mybots` → ваш бот → **Bot Settings → Menu Button** →
пришлите ссылку на сайт и подпись кнопки, например «Карта».

### Mini App со своей ссылкой (нужна для QR-кодов)

В @BotFather: `/newapp` → выберите бота → название, описание, картинка 640×360 →
ссылка на сайт → короткое имя, например `map`. После этого приложение открывается ссылкой
`https://t.me/<имя_бота>/map`.

### Прямые ссылки на место (QR-коды у столовых)

```
https://t.me/<имя_бота>/map?startapp=place_3
```

Telegram передаст приложению `start_param = place_3`, и сразу откроется карточка места № 3.
В обычном браузере то же самое делает `https://<сайт>/?place=3`.
Из такой ссылки можно сделать QR-код любым генератором.

Если место не найдено (нет такого `id` или оно скрыто), откроется обычная карта
с сообщением «Место №N не найдено».

### Кнопка «Открыть карту» в самом боте (aiogram 3)

Это делается в репозитории бота. Нужен `WebAppInfo`:

```python
from aiogram import Router
from aiogram.filters import CommandStart
from aiogram.types import (InlineKeyboardButton, InlineKeyboardMarkup,
                           MenuButtonWebApp, Message, WebAppInfo)

WEBAPP_URL = "https://<ваш-логин>.github.io/<имя-репозитория>/"
router = Router()

@router.message(CommandStart())
async def start(message: Message):
    keyboard = InlineKeyboardMarkup(inline_keyboard=[[
        InlineKeyboardButton(text="Открыть карту", web_app=WebAppInfo(url=WEBAPP_URL)),
    ]])
    await message.answer("Карта столовых и коворкингов МАИ", reply_markup=keyboard)

# Кнопку меню можно поставить и из кода (вместо BotFather), например при запуске бота:
# await bot.set_chat_menu_button(
#     menu_button=MenuButtonWebApp(text="Карта", web_app=WebAppInfo(url=WEBAPP_URL)))
```

Inline-кнопка с `web_app` работает только в личном чате с ботом. Чтобы открыть приложение
сразу на нужном месте из бота, давайте ссылку `https://t.me/<имя_бота>/map?startapp=place_3`.

Приложение не отправляет никаких данных пользователя ни боту, ни куда-либо ещё, аналитики нет.

## 7. Данные из опубликованной таблицы

Когда команда перейдёт на общую Google-таблицу:

1. Сделайте таблицу с двумя листами: `objects` и `menu`, с теми же колонками, что в CSV.
2. **Файл → Поделиться → Опубликовать в интернете** → выберите лист `objects` → формат
   **CSV** → «Опубликовать». Скопируйте ссылку. То же для листа `menu`.
   Ссылки выглядят так: `https://docs.google.com/spreadsheets/d/e/…/pub?gid=0&single=true&output=csv`.
3. **Проверьте, что ссылку можно читать с другого сайта (CORS).** Откройте приложение
   (локально или на GitHub Pages), нажмите `F12` → Console и выполните:

   ```js
   fetch('ВАША_ССЫЛКА').then(r => r.text()).then(t => console.log(t.slice(0, 200)))
   ```

   Если напечатались первые строки таблицы — всё хорошо. Если красная ошибка со словом
   **CORS** — этот источник браузер читать не даст, нужен другой способ публикации.
   Опубликованные Google-таблицы обычно разрешают такое чтение, но проверить нужно.
4. В `js/config.js` замените пути:

   ```js
   DATA_SOURCES: {
     objects: 'https://docs.google.com/spreadsheets/d/e/…/pub?gid=0&single=true&output=csv',
     menu: 'https://docs.google.com/spreadsheets/d/e/…/pub?gid=123456&single=true&output=csv',
   },
   ```

Больше ничего менять не нужно: остальной код не знает, откуда пришли данные.

Учтите: Google обновляет опубликованный CSV не мгновенно (до нескольких минут), и его
доступность зависит от Google. Держите копию данных в `data/*.csv`, чтобы быстро вернуться.

## 8. Если что-то не работает

Первым делом откройте консоль браузера: `F12` → вкладка **Console**. Все проблемы
с данными пишутся туда с id места и названием поля.

| Что видно | Что проверить |
|---|---|
| Белый экран или «Загрузка…» навсегда | Открыто через `file://`? Запустите сервер (раздел 2). Есть ли в консоли красные ошибки? |
| «Откройте приложение через локальный сервер…» | Вы открыли `index.html` двойным кликом — см. раздел 2 |
| «Не удалось загрузить карту кампуса» | Есть ли файл `media/map.jpg` (имя точно такое, маленькими буквами)? |
| «Не удалось загрузить данные» | Есть ли `data/objects.csv`? Если данные из таблицы — работает ли ссылка, нет ли ошибки CORS (раздел 7)? Есть ли колонка `id`? |
| Метки нет на карте | В консоли есть предупреждение про `map_x/map_y`? Не стоит ли `visible = нет`? Не отфильтровано ли место (фильтры сверху)? |
| Метка не в том месте | Картинку меняли? Координаты нужно пересчитать (раздел 3) |
| В карточке «нет данных» | В консоли предупреждение: какое поле записано не по правилам (раздел 4) |
| Русские буквы — «кракозябры» | CSV сохранён не в UTF-8. В Excel: «Сохранить как → CSV UTF-8» |
| Не работает кнопка «Маршрут» | Есть ли `lat` и `lon` у места? Без них кнопки нет |

### Кэш: «я всё поменял, а в Telegram старая версия»

- GitHub Pages обновляется 1–2 минуты после `git push`, а браузеры хранят файлы
  до 10 минут. Подождите.
- В браузере на компьютере: `Ctrl+F5` (обновить без кэша).
- В Telegram Desktop: в окне Mini App откройте меню «⋮» → **Reload Page** (перезагрузить).
- На телефоне: полностью закройте Mini App (не свернуть) и откройте снова; если не помогло —
  в настройках Telegram «Данные и память → Использование памяти → Очистить кэш».
- Надёжный способ: поменяйте ссылку в @BotFather на `https://<сайт>/?v=2` (потом `?v=3` и т.д.) —
  для Telegram это новый адрес, и он загрузит всё заново.

Данные (CSV) приложение каждый раз перепроверяет у сервера, поэтому изменения в таблицах
видны после обычного перезапуска.
