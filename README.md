# Карта столовых и коворкингов МАИ (Telegram Mini App)

Студенческий проект по дисциплине «Обучение служением». Интерактивная карта основной
территории МАИ (метро «Сокол»): столовые, буфеты, кафе и коворкинги. Нажимаешь на метку —
снизу выезжает карточка: открыто ли сейчас, где находится, часы работы, цены, доступность,
кнопки «Меню» и «Маршрут».

> Это неофициальный студенческий проект, а не сервис МАИ.

Что умеет:

- карта кампуса с метками, приближение пальцами;
- «Открыто сейчас» по московскому времени (с учётом перерыва и выходных);
- фильтры: еда, коворкинги, открыто сейчас, ♿ доступно для маломобильных;
- список мест с поиском по названию;
- меню с ценами и отметкой «вег.»;
- пеший маршрут в Яндекс Картах;
- ссылки и QR-коды на конкретное место;
- светлая и тёмная тема (в Telegram — цвета темы Telegram);
- работает и в Telegram, и в обычном браузере.

## 1. Как устроено

Ни сервера, ни базы данных нет — это статический сайт (его можно разместить на GitHub Pages).

```
картинка карты (media/map.jpg) + места (data/objects.csv) + меню (data/menu.csv)
```

- **Карта — это картинка.** Библиотека [Leaflet](https://leafletjs.com) в режиме `L.CRS.Simple`
  позволяет двигать и приближать её как обычную карту.
- **Метки** ставятся по `map_x`, `map_y` — пикселям картинки от левого верхнего угла.
- **Данные** — CSV-таблицы, их разбирает [Papa Parse](https://www.papaparse.com).

```
├── index.html       — разметка и все тексты интерфейса
├── css/style.css    — внешний вид, светлая и тёмная тема
├── js/
│   ├── config.js    — НАСТРОЙКИ: пути к данным, типы мест, категории меню, ссылка маршрута
│   ├── data.js      — загрузка и проверка CSV
│   ├── hours.js     — «открыто сейчас»
│   ├── map.js       — карта и метки
│   └── app.js       — всё остальное: фильтры, список, карточка, меню, Telegram
├── data/            — objects.csv (места) и menu.csv (меню)
├── media/           — map.jpg (карта) и photos/ (фото мест)
├── vendor/          — Leaflet 1.9.4 и Papa Parse 5.7.0 (лежат в проекте, CDN бывают недоступны)
├── bot/             — Telegram-бот на aiogram (кнопка «Открыть карту»)
└── tests/           — проверки (node --test или tests/tests.html)
```

## 2. Запуск на своём компьютере

Нужен Python 3. В папке проекта:

```bash
python -m http.server
```

и откройте **http://localhost:8000** (на Windows, если `python` не находится, — `py -m http.server`).

Просто открыть `index.html` двойным кликом нельзя: с адресом `file://` браузер не даёт загрузить
модули и CSV. Приложение тогда подскажет запустить сервер.

| Адрес | Что делает |
|---|---|
| http://localhost:8000/?place=3 | сразу открыть карточку места № 3 |
| http://localhost:8000/?debug=1 | режим разметки: нажмите на карту — увидите `map_x` и `map_y` |
| http://localhost:8000/tests/tests.html | проверки в браузере |

### Тесты

Проверяются разбор таблиц, часы работы, «открыто сейчас», ссылки `place_N` и демо-данные.

- С Node.js 20+: `node --test` (в конце должно быть `# fail 0`). На GitHub они запускаются сами
  при каждом push (`.github/workflows/tests.yml`).
- Без Node.js: запустите сервер и откройте http://localhost:8000/tests/tests.html.

## 3. Как добавить место

1. Добавьте строку в `data/objects.csv` (или в Google-таблицу, см. раздел 6).
2. Откройте приложение с `?debug=1` и нажмите на карте, где должна стоять метка. Кнопка
   «Скопировать» копирует `map_x` и `map_y` — в таблице они сами встанут в две соседние ячейки.
3. Для кнопки «Маршрут» найдите в Яндекс Картах вход в корпус: нажмите на него, внизу появятся
   координаты вида `55.811070, 37.500900`. Первое число — `lat`, второе — `lon`.
4. Фото (по желанию) положите в `media/photos/`, имена файлов впишите в колонку `photos`.
5. Обновите страницу (`Ctrl+F5`). Если в строке ошибка, в консоли браузера (`F12` → Console)
   будет предупреждение с id места и названием поля.

### Колонки `objects.csv`

| Колонка | Что писать | Пример |
|---|---|---|
| `id` | уникальный номер > 0. Он же номер на метке и в ссылке `place_N` | `3` |
| `type` | `столовая` / `буфет` / `кафе` / `автоматы` / `коворкинг` | `кафе` |
| `name` | название | `Кафе в 24 корпусе` |
| `building`, `floor` | корпус и этаж | `24`, `1` |
| `how_to_find` | как найти, коротко | `Вход со двора` |
| `hours_weekdays` | часы в будни: `ЧЧ:ММ-ЧЧ:ММ` или `закрыто` | `08:30-17:00` |
| `hours_saturday` | часы в субботу, так же | `закрыто` |
| `break` | перерыв (во все рабочие дни) или пусто | `13:00-13:30` |
| `payment` | оплата, любым текстом | `карта, наличные` |
| `lunch_price` | цена обеда, **только цифры** | `350` |
| `vegetarian` | `да` / `нет` | `да` |
| `accessible` | для маломобильных: `да` / `частично` / `нет` | `частично` |
| `accessibility_note` | пояснение | `Лифта нет` |
| `lat`, `lon` | координаты входа | `55.81107`, `37.50090` |
| `map_x`, `map_y` | метка на картинке, пиксели (см. `?debug=1`) | `391`, `313` |
| `seats` | число мест (коворкинги) | `30` |
| `sockets` | `много` / `мало` / `нет` | `много` |
| `wifi` | `да` / `нет` | `да` |
| `noise` | `тихо` / `шумно` | `тихо` |
| `photos` | файлы из `media/photos/` через запятую | `kafe-1.jpg,kafe-2.jpg` |
| `visible` | `нет` — скрыть место (например, ремонт) | `да` |
| `updated` | когда проверяли: `ДД.ММ.ГГГГ` | `03.11.2026` |

Правила:

- Воскресенье всегда выходной. Работа «через полночь» не поддерживается.
- «Открыто сейчас» считается **по Москве**, даже если на телефоне другой часовой пояс.
- Пустая ячейка — поле не показывается. Ячейка с ошибкой (`с 8 до 5`, `300 руб.`) — «нет данных»
  и предупреждение в консоли.
- Строка с неправильным `id` пропускается. Место без `map_x`/`map_y` есть только в списке.
- Ячейку с запятой берите в кавычки: `"карта, наличные"` (Excel и Google Таблицы делают это сами).
- Excel с русскими настройками сохраняет CSV через `;` — это тоже работает. Сохраняйте как
  **«CSV UTF-8»**, иначе вместо русских букв будут «кракозябры».

### Колонки `menu.csv`

| Колонка | Что писать | Пример |
|---|---|---|
| `object_id` | `id` места | `1` |
| `category` | `комплекс` / `первое` / `второе` / `гарнир` / `салат` / `выпечка` / `напитки` | `первое` |
| `dish` | название блюда | `Борщ со сметаной` |
| `price` | цена, только цифры | `120` |
| `vegetarian` | `да` / `нет` | `нет` |
| `updated` | `ДД.ММ.ГГГГ` | `01.11.2026` |

Блюдо с неизвестной категорией попадает в «Другое».

### Фото

Имена латиницей без пробелов (`stolovaya-guk-1.jpg`), JPEG/PNG/WebP, ширина ~1200 px, до 300 КБ
(сжать можно на [squoosh.app](https://squoosh.app)). Если файла нет, фото просто не показывается.

### Демо-данные

Сейчас в таблицах **демонстрационные** места. Специально: у «Демо-буфета 1» часы записаны
с ошибкой («с 8 до 5»), а «Демо-коворкинг 2» скрыт (`visible = нет`). Координаты примерные.
Перед запуском замените демо-строки настоящими данными.

## 4. Картинка карты

Сейчас в `media/map.jpg` схема с сайта **mai-sten.online** (800×700). **Перед публикацией
спросите у автора разрешение.** Для чёткой карты нужна картинка 3000–4000 px по длинной стороне
(не больше 4096) и до 2–3 МБ. Размеры приложение узнаёт само.

Если поменять картинку на другую по размеру, метки съедут. Пересчитайте:
`новый map_x = старый map_x × новая ширина / старая ширина` (так же для `map_y`).

## 5. Публикация и Telegram

### GitHub Pages

**Settings → Pages → Deploy from a branch**, ветка `main`, папка `/ (root)` → **Save**.
Через 1–2 минуты сайт будет по адресу `https://<логин>.github.io/<репозиторий>/`
(для этого репозитория — https://egorpozdnyakov.github.io/mai_navigation_bot/).
После каждого `git push` сайт обновляется сам.

### Бот

В папке `bot/` — простой бот на [aiogram 3](https://docs.aiogram.dev): на `/start` присылает кнопку
«Открыть карту» и ставит кнопку «Карта» рядом с полем ввода.

1. Создайте бота в [@BotFather](https://t.me/BotFather) (`/newbot`) и скопируйте токен.
2. Запустите:

   ```bash
   pip install -r bot/requirements.txt
   BOT_TOKEN=123:abc WEBAPP_URL=https://<логин>.github.io/<репозиторий>/ python bot/bot.py
   ```

   На Windows вместо `BOT_TOKEN=... python ...`: `set BOT_TOKEN=123:abc` и затем `python bot/bot.py`.

Бот должен работать постоянно (на сервере, VPS или бесплатном хостинге). Без бота Mini App
тоже можно открыть: в @BotFather → `/mybots` → бот → **Bot Settings → Menu Button** → ссылка на сайт.

### Ссылки и QR-коды на место

- `https://t.me/<имя_бота>?start=place_3` — бот пришлёт кнопку, которая откроет место № 3;
- `https://t.me/<имя_бота>/map?startapp=place_3` — сразу открывает приложение на месте № 3
  (нужно один раз создать Mini App в @BotFather: `/newapp`, короткое имя `map`);
- `https://<сайт>/?place=3` — то же самое в обычном браузере.

Если места нет (или оно скрыто), откроется карта с сообщением «Место №N не найдено».
Приложение не собирает и никуда не отправляет данные пользователей.

## 6. Данные из Google-таблицы

1. Сделайте таблицу с листами `objects` и `menu` с теми же колонками, что в CSV.
2. **Файл → Поделиться → Опубликовать в интернете** → лист `objects` → формат **CSV** →
   «Опубликовать», скопируйте ссылку. То же для `menu`.
3. Впишите ссылки в `js/config.js` вместо `data/objects.csv` и `data/menu.csv`.
4. Проверьте, что браузер может читать ссылку: `F12` → Console →
   `fetch('ССЫЛКА').then(r => r.text()).then(console.log)`. Ошибка со словом **CORS** — такой
   источник не подойдёт.

Google обновляет опубликованный CSV не сразу (до нескольких минут). Держите копию данных в `data/`.

## 7. Если что-то не работает

Сначала откройте консоль браузера: `F12` → **Console**.

| Что видно | Что проверить |
|---|---|
| «Откройте приложение через локальный сервер…» | Вы открыли `index.html` двойным кликом — см. раздел 2 |
| «Не удалось загрузить карту кампуса» | Есть ли файл `media/map.jpg` (имя маленькими буквами)? |
| «Не удалось загрузить данные» | Есть ли `data/objects.csv`? Работает ли ссылка на таблицу, нет ли ошибки CORS? |
| Метки нет на карте | Предупреждение про `map_x/map_y`? `visible = нет`? Включён фильтр? |
| В карточке «нет данных» | В консоли написано, какое поле записано не по правилам |
| «Кракозябры» | CSV сохранён не в UTF-8 |
| Нет кнопки «Маршрут» | У места нет `lat` и `lon` |
| В Telegram старая версия | Подождите пару минут; закройте Mini App полностью и откройте снова; или поменяйте ссылку в @BotFather на `https://<сайт>/?v=2` |
